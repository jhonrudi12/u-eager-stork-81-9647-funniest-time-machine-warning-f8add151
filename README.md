A one-line warning label for a time machine, written to get the biggest laugh in 120 characters or fewer.

## Entry

> WARNING: If you meet yourself, say nothing. He already regrets this conversation, and so do you.

## Run

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` and prints the same line. Deterministic, no network, no input.
